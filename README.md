# BT-ViT: Biomarker-Token Vision Transformer for glaucoma clinical decision support

BT-ViT classifies glaucoma from optic-disc-centred fundus images. In the same network it also segments
the optic disc and cup, computes **12 clinical biomarkers** from its own masks (cup-to-disc ratios,
ISNT rim fractions, rim ratio, disc size and shape, boundary strength) and feeds them back to the
transformer as *clinical tokens*.

- **Training data:** ORIGA + REFUGE/REFUGE2.
- **External tests:** RIM-ONE DL and DRISHTI-GS, never seen in training.
- **Reference paper:** Nasrin *et al.*, *J. Clin. Med.* 2026, 15, 5651.
- **Study design:** [METHODOLOGY.md](METHODOLOGY.md). **All results:** [RESULTS.md](RESULTS.md).

---

## Quick start

```bash
pip install -r requirements.txt     # Python 3.11, PyTorch 2.5 + CUDA 12.1

python run.py status                # what has been run and what is missing
python run.py prepare               # P0: datasets -> splits -> disc localiser -> ROI crops
python run.py train --model btvit   --seeds 2026 2027 2028 2029 2030
python run.py train --model purevit --seeds 2026 2027 2028 2029 2030
python run.py compare               # P3: 5-seed comparison, DeLong tests, bootstrap CIs
python run.py results               # print all result tables and write RESULTS.md
python run.py figures               # regenerate the architecture figure and LaTeX tables
```

`run.py` is the single entry point. Every command prints numbered stages with `[done]` / `[FAIL]`
status and timing, and stops with a clear message if a stage fails.

## Pipeline

| Stage | Command | What it does | Main output |
|---|---|---|---|
| P0 | `run.py prepare` | Unify 5 datasets; fixed splits; train the disc localiser; crop every image around the disc | `data/cdss/roi_manifest.csv` |
| P2 | `run.py train` | Train BT-ViT (V2 + λ_bio = 1) or the pure ViT under one shared protocol | `runs/p2/.../metrics.json` |
| P3 | `run.py compare` | 5 seeds per model, ensembles, DeLong tests, bootstrap 95% CIs | `runs/p3/final_comparison.json` |
| Report | `run.py results` / `figures` | Result tables, architecture figure, LaTeX tables | `RESULTS.md`, `figures/` |

**Protocol, identical for every model** (`cdss/config.py`):
- 50 epochs, batch 16, AdamW; learning rate 1e-4 (pretrained) / 3e-4 (new layers).
- Early stopping on validation AUC (patience 15); class-balanced sampling; flip test-time augmentation.
- Decision thresholds fitted on validation only.

## Results

### Architecture variants

| Variant | Description | Params |
|---|---|---|
| V0: Pure ViT | DeiT-Tiny (ImageNet), image only (baseline) | 5.5 M |
| V1: BT-ViT v1 | Conv stem + 8 DeiT blocks; segmentation branch; clinical tokens and rim-guided attention in blocks 5–8 | 4.9 M |
| V2: BT-ViT v2 | Full pretrained DeiT-Tiny (12 blocks); segmentation branch after block 4; gated clinical tokens and rim-guided attention in blocks 9–12 | 6.7 M |

**V2 training-recipe search** (selected on validation AUC):
- EMA: 0.946, not adopted.
- Label smoothing: 0.944, not adopted.
- **λ_bio = 1.0: 0.948, adopted.**
- Open gates: 0.947, not adopted.

### Final comparison: BT-ViT (V2 + λ_bio = 1) vs pure ViT, 5 seeds each

| AUC, mean ± SD | Internal test (n = 290) | RIM-ONE, external (n = 485) | DRISHTI-GS, external (n = 101) |
|---|---|---|---|
| Pure ViT | 0.936 ± 0.003 | 0.936 ± 0.005 | 0.862 ± 0.025 |
| BT-ViT | **0.942 ± 0.004** | **0.942 ± 0.008** | 0.860 ± 0.016 |

| 5-seed ensembles | Internal test | RIM-ONE | DRISHTI-GS |
|---|---|---|---|
| Pure ViT, AUC [95% CI] | 0.943 [0.909, 0.971] | 0.949 [0.928, 0.967] | 0.876 [0.804, 0.937] |
| BT-ViT, AUC [95% CI] | 0.944 [0.910, 0.972] | 0.951 [0.931, 0.968] | 0.864 [0.789, 0.929] |
| DeLong *p* | 0.84 | 0.52 | 0.34 |
| Sensitivity on external sets (pure / BT-ViT) | – | 0.70 / **0.85** | 0.61 / **0.76** |

**Summary:**
- BT-ViT matches a strong pretrained ViT in discrimination (no significant AUC difference between the ensembles).
- It keeps higher sensitivity on the unseen datasets.
- It additionally provides disc/cup segmentation and clinical biomarkers for the decision-support report.
- The learned gates stayed closed: its benefit comes from multi-task supervision, not from token fusion.
